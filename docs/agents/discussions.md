# Discussions

A discussion is several agents talking one question through in rounds, while nobody changes anything.

## Who starts one

An agent starts a discussion when it has the `discuss` tool. You cannot start one yourself, but you
can join it.

An agent invites 1 to 5 agents or roles, for 1 to 20 rounds (3 unless it says otherwise). The agent
that opened it speaks last in each round.

## When it ends

A discussion ends when nobody has anything to add, at its round limit, when it reaches its token
budget, or when you end it. It also ends at the message's and the project's own limits.

Each step of a speech sends the speaker's whole work so far again, so the token count grows faster
than the talk does. The budget is set under Settings › This project › Limits and money › **A discussion's tokens, at most**. Empty means
no limit. It applies to discussions opened after you save it. A chat with no folder has no token limit
for its discussions.

## The Discussion window

The **Discussion** window shows its state ("Round 2 of 3", or why it ended), and each round with what
each agent said, or that it has nothing to add.

- **Say something to everyone**, then **Say**, adds your words.
- **End discussion** ends it.
