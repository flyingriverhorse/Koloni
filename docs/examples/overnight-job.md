# A job while you're away

Jobs that run while you are away, for an hour or the night, each in its own copy of the project, so
nothing changes until you take it in.

## Before you go

1. In a chat with a folder, tell the Orchestrator you are going away and what to work on meanwhile. It
   proposes the jobs on a **While you're away** card. The jobs run at this chat's permission level
   and on its model: below **Full auto**, a command no rule covers waits for you.
2. Press **Change the list** to edit the jobs and add what is kept out (files or folders no job may
   change), then **Save the list**. On the card itself, set when to stop: **Stop at** a time, or after
   an amount of money. With neither set, the jobs run until they are done: there is no default
   spend limit, only your monthly budget if you set one.
3. If you want the Orchestrator to answer the safe questions for you, use **Let the Orchestrator answer
   what it safely can** on the card. It stays on for the project after the jobs. Otherwise every
   question waits for you.
4. Press **Start**. The top bar shows which job runs, with **Stop all**.

Leave KOLONİ running: closing it ends the jobs.

## When you're back

1. KOLONİ opens on the report on the canvas: what was done, what waits for your word, what could not
   be done. The chat says the same in one line.
2. For a job that waits for a command, a change, a web request or an agent to open, press **Allow and
   go on** or **Refuse**. For a question, **Open its chat** and answer there.
3. Look at each job's changes (**See the changes**), then **Take in** the ones you want, or **Take in
   all**.
4. **Try again** runs a job that could not be done, or was stopped, again as an ordinary turn.
5. **Proposed while you were away, not started** lists jobs the agents thought of; **Add to To-do**
   keeps them.

See [Work while you're away](../automation/overnight.md).
