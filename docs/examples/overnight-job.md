# A job while you're away

To-do tasks that run while you are away, for an hour or the night, each in its own copy of the
project, so nothing changes until you take it in.

## Before you go

1. In a chat with a folder, tell the Orchestrator you are going away and what to work on meanwhile.
   It puts each piece on your [To-do](../automation/todo.md) list and offers one line under its
   answer: "☾ Go away now?". The tasks run at this chat's permission level and on its model: below
   **Full auto**, a command no rule covers waits for you.
2. Press **Change** on that line - or **☾ Away** on the chat's status line - to see the Away panel:
   the tasks from this chat are ticked; tick others from To-do too, and put them in order with
   **Move up** / **Move down**. Set when to stop (**Until** a time, or **spend at most** an amount) and
   what is kept out (files or folders no task may change). With neither limit set, the tasks run
   until they are done: there is no default spend limit, only your monthly budget if you set one.
3. Press **Go away**. The chat finishes its turn, then the tasks start one at a time. The status line
   says which, and how many cards were decided for you.

The Orchestrator decides for you, at once, what it may: an agent's question, a recipe's "Ask me",
opening a sub-agent on its role's own model. Everything else waits for you. Leave KOLONİ running:
closing it ends Away.

## When you're back

1. Press **I'm back**, or write in the chat. The chat shows one summary: "While you were away (23:10 –
   07:42): 2 of 2 To-do done · 3 decided for you · 1 waits".
2. For a task that waits for a command, a change, a web request or an agent to open, press **Allow and
   go on** or **Refuse**. For a question, **Open its chat** and answer there.
3. **Review and take in** opens Ready for you; **On the canvas** opens the report. Look at each task's
   changes (**See the changes**), then **Take in** the ones you want, or **Take in all**.
4. **Try again** runs a task that could not be done, or was stopped, again as an ordinary turn.
5. **Proposed while you were away, not started** lists tasks the agents thought of; **Add to To-do**
   keeps them.

See [Work while you're away](../automation/overnight.md).
