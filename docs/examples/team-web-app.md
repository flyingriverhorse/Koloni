# A web app with a team

A small web app, built by the ready **Web app** team, from the first message to Take in.

1. **Open a folder** for the app (the folder button → **Open a folder…**). An empty folder is fine.
2. **Pick the team.** On the canvas, **Teams for this chat** → **Manual**, then the **Web app** team
   with its default recipe. Or leave **Orchestrator decides** and let it pick.
3. **Choose a level.** Keep **Ask before changes** the first time. The team works in a working copy,
   so your folder does not change until you take the work in.
4. **Write the message**, for example: "A one-page to-do list app in plain HTML and JavaScript, with a
   test." With **Plan first** on, you approve a plan first.
5. **Watch the canvas.** It draws the team as a frame with its steps and agents, their tools, commands
   and files. Answer the cards as they come; **Ready** on the rail counts what waits.
6. **Preview it.** An agent can start a dev server and show the page; running servers are listed under **Previews** in the Workspace.
7. **Take it in.** When the recipe ends, the **Teams' work is ready** card asks: **Take in**, **Fix the
   findings** (if reviewers left findings), or **Ask for changes** with what to change.
8. **Undo if needed.** **Undo these changes** takes a turn's changes back, and names what it cannot
   take back.

See [Teams](../agents/teams.md) and [Ready and approval cards](../use/ready.md).
