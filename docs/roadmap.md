# Roadmap

What is planned after 0.1.0. Plans change; nothing here is promised.

## Planned for 0.2.0

- **Go back to any step of a turn** and run it again from there. KOLONİ keeps a hidden snapshot of each
  step.
- **Watch a pull request**: its checks and reviews on the canvas as a **Watch** node, and an agent that
  fixes what fails.
- **Add a GitHub issue to the To-do** (a chat can already start from one).
- **Pull requests outside GitHub**, such as GitLab.
- **Who wrote this line**: the agent and the turn behind each change.
- **Codex and Copilot sessions that carry on across turns**, and support for Copilot Fusion, a model
  choice in GitHub Copilot CLI.
- **Voice**: your own speech server, hands-free spoken conversation, and a voice for each role.
- **Models that make images, audio and video**, on the canvas and for roles.
- **Remote MCP servers** (reached over HTTP, with sign-in).
- **Plugins** that install a package's parts into KOLONİ.
- **Arranging agents on the canvas**: tools to group and place them.
- **Screen control**: only apps you pick, each action or session asked, never in a turn nobody watches.
  This needs a design first.

## May come later

- Versioned documentation, and a "What's new" note after an update.
