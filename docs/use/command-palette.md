# Command palette (Ctrl+K)

Press **Ctrl+K** (⌘K on a Mac) anywhere to open **Go to**: "A page, a conversation, a role, a model…".
Type to filter, use the arrow keys to move, Enter to go, Esc to close.

It finds:

- **Pages**: Canvas, Chats, Ready for you, Board, To-do, Agents, Models, Tools, Memory, Knowledge, Triggers,
  Usage, Settings.
- **Conversations**, by title.
- **Roles** and **Models**.
- **Tool servers**.
- **Settings**: each section of the project's settings, while a chat with a folder is open.
- **Help**: **Show the first steps**.
- **Search in messages**: searches the project's memory and earlier messages for what you typed (see
  [Memory](../memory.md)).
