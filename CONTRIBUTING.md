# Contributing

Thanks for considering a contribution to KOLONİ.

- **Sign off every commit** (Developer Certificate of Origin): `git commit -s`.
- **CLA:** by opening a pull request you agree to [`CLA.md`](CLA.md), which grants the project the
  right to relicense your contribution. KOLONİ is AGPL-3.0-or-later ([`LICENSE`](LICENSE)).
- Keep a change small and focused, and deliver a behaviour end to end: backend and page together.
- `scripts/verify.ps1` must pass (on Linux and macOS, run it with `pwsh`).
- Never add secrets, caches or `runtime/` output. Check the licence of any source code or asset
  before you take it.
- Be kind: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Report a security problem privately, as
  [`SECURITY.md`](SECURITY.md) says.

The full guide for contributors, with the changelog's rules, is
[Contributing](docs/developer/contributing.md); tests are in [Tests and verify](docs/developer/verify.md).
